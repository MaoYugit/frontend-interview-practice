### 你了解 Vue 中的过滤器吗？它有哪些应用场景？

这道题我从过滤器的作用、语法、典型场景，以及 Vue 3 中的变化来回答。

---

**一、过滤器是什么**

过滤器是 Vue 提供的一种文本格式化工具，专门用于模板插值和 `v-bind` 表达式中，对数据进行简单的二次处理。它不会改变原始数据，只影响显示结果。

---

**二、基本语法**

**定义过滤器：**

```javascript
// 全局注册
Vue.filter('capitalize', function(value) {
  if (!value) return ''
  value = value.toString()
  return value.charAt(0).toUpperCase() + value.slice(1)
})

// 局部注册
export default {
  filters: {
    capitalize(value) {
      if (!value) return ''
      return value.charAt(0).toUpperCase() + value.slice(1)
    }
  }
}
```

**使用过滤器：**

```html
<!-- 插值表达式中 -->
<p>{{ message | capitalize }}</p>

<!-- 链式调用 -->
<p>{{ message | filterA | filterB }}</p>

<!-- 传参 -->
<p>{{ price | currency('¥') }}</p>

<!-- v-bind 中 -->
<div :title="rawText | format"></div>
```

管道符 `|` 左边的值作为第一个参数传给过滤器函数，后续参数依次传入。

---

**三、典型应用场景**

1. **文本格式化**：首字母大写、全部大写/小写、截断长文本并补省略号
2. **货币/数字格式化**：价格加货币符号、千分位分隔、保留固定小数位，如 `99.9 | currency('¥')` 输出 `¥99.90`
3. **日期格式化**：将时间戳或 ISO 字符串转成 `YYYY-MM-DD HH:mm:ss` 等可读格式，如 `1630000000000 | formatDate('YYYY-MM-DD')`
4. **状态映射**：将后端返回的状态码转为用户可读文案，如 `0 | statusText` 显示“待审核”
5. **数组/对象预处理**：在 `v-for` 中对数据进行过滤或排序（不推荐，应用计算属性替代）

---

**四、过滤器的局限**

- 只能在 `{{ }}` 插值和 `v-bind` 中使用，无法在 `v-model`、`v-on` 等指令或组件属性中使用
- 逻辑分散在模板和 JS 之间，复杂逻辑会让代码难以维护
- 本质是纯函数，适合简单的显示层格式化，不适合做数据层转换

---

**五、Vue 3 中的变化**

**Vue 3 彻底移除了过滤器功能**，官方推荐用**计算属性**或**全局方法**替代：

```javascript
// 推荐：计算属性
computed: {
  formattedPrice() {
    return `¥${this.price.toFixed(2)}`
  }
}

// 或全局方法
app.config.globalProperties.$filters = {
  currency(value, symbol = '¥') {
    return `${symbol}${Number(value).toFixed(2)}`
  }
}
```

迁移理由是：过滤器本质上就是函数调用，用方法和计算属性表达更直观，没有额外的语法学习成本，且能更好地利用 Tree-shaking 优化打包体积。

---

**总结**

过滤器是 Vue 2 的文本格式化工具，适用于插值和属性绑定中的简单加工。但 Vue 3 已废弃它，统一用计算属性和方法替代，这既简化了模板语法，也让数据处理逻辑更集中、更易维护。如果面试是 Vue 2 的技术栈，过滤器仍需要掌握；如果是 Vue 3，说明清楚替代方案即可。
