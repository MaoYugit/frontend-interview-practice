### Vue3-Vue Router获取路由参数

在 Vue Router 中，获取路由传递过来的参数主要取决于**参数的传递形式（Query 还是 Params）**以及你所使用的**组件开发范式（组合式 API 还是 选项式 API）**。

以下是全面、系统整理的路由参数获取方法及最佳实践：

---

### 一、 路由参数的两大核心形式

在 Vue Router 中，最常用的传参形式有两种：

#### 1. Query 传参（查询参数）
* **URL 表现形式**：`/user?id=123&name=tony`
* **路由配置**：常规配置即可，无需在路径上声明参数，如 `path: '/user'`。
* **获取对应属性**：通过 `route.query` 对象获取。

#### 2. Params 传参（路径参数 / 动态路由参数）
* **URL 表现形式**：`/user/123`
* **路由配置**：必须在路由配置的 `path` 中通过冒号 `:` 声明动态片段，例如 `path: '/user/:id'`。
* **获取对应属性**：通过 `route.params` 对象获取。

> **⚠️ 注意（面试加分项）**：
> 在 **Vue Router 4** 中，**已经移除了在 `router.push` 时通过命名路由（name）隐式传递未在 path 中定义的 params 的行为**（例如：在配置 `path: '/user'` 的情况下传递 `params: { secret: 'abc' }`）。因为这种隐式参数在页面刷新后会彻底丢失。在当前版本中，所有需要通过 `params` 传递的参数，**必须**在 `path` 中声明占位符（如 `/:id`）。

---

### 二、 在不同开发范式下如何获取参数

根据项目中采用的语法结构，有以下几种主要的获取方式：

#### 1. 组合式 API (Composition API - Vue 3 `<script setup>`)
使用 Vue Router 提供的 `useRoute()` 组合式函数获取当前的路由对象：

```html
<script setup>
import { useRoute } from 'vue-router'

// 获取当前路由对象实例
const route = useRoute()

// 1. 获取 Query 参数 (e.g. /user?id=123)
console.log(route.query.id) // 输出: '123'

// 2. 获取 Params 参数 (e.g. /user/123)
console.log(route.params.id) // 输出: '123'
</script>
```

#### 2. 选项式 API (Options API - Vue 2 或 Vue 3 经典模式)
通过组件实例上的内置属性 `this.$route` 直接获取：

```javascript
export default {
  mounted() {
    // 1. 获取 Query 参数
    console.log(this.$route.query.id)
    
    // 2. 获取 Params 参数
    console.log(this.$route.params.id)
  }
}
```

#### 3. 模板 (Template) 中直接使用
如果在模板中只需要展示参数，可以直接通过 `$route` 全局属性访问：

```html
<template>
  <div>
    <p>当前用户 ID (Params): {{ $route.params.id }}</p>
    <p>当前搜索关键字 (Query): {{ $route.query.keyword }}</p>
  </div>
</template>
```

---

### 三、 最佳实践：路由组件传参 (Route Props)

直接在组件中调用 `useRoute()` 或 `this.$route` 会使该组件与当前的路由系统**强耦合**，导致组件难以在非路由场景下复用，且不利于单元测试。

Vue Router 提供了 **`props` 选项**，可以将路由参数转换为组件的 `props`，实现组件与路由的解耦。

#### 1. Params 参数转为 Props
* **路由配置**：
  ```javascript
  {
    path: '/user/:id',
    component: UserDetail,
    props: true // 开启此项，route.params 中的参数会自动作为 props 注入到组件中
  }
  ```
* **组件内接收**：
  ```html
  <script setup>
  // 直接声明并接收 id，无需再调用 useRoute()
  defineProps({
    id: {
      type: String,
      required: true
    }
  })
  </script>
  ```

#### 2. Query 参数转为 Props（使用函数模式）
如果需要将 `query` 查询参数也转为 props，可以在路由配置中使用函数形式：

* **路由配置**：
  ```javascript
  {
    path: '/user',
    component: UserDetail,
    // route 作为一个参数传入，返回一个对象作为组件的 props
    props: route => ({ 
      id: route.query.id, 
      name: route.query.name 
    })
  }
  ```
* **组件内接收**：
  ```html
  <script setup>
  defineProps({
    id: String,
    name: String
  })
  </script>
  ```

### 四、 参数变化的响应与监听问题

当路由参数发生改变（例如用户从 `/user/1` 跳转到 `/user/2`）时，由于它们映射的是同一个组件，**组件实例会被复用，这意味着生命周期钩子（如 `onMounted` / `mounted`）不会重新触发**。

如果需要在参数发生变化时重新拉取数据，有以下三种应对方案：

1. **Watch 监听路由对象**（最常见）：
   ```javascript
   import { watch } from 'vue'
   import { useRoute } from 'vue-router'
   
   const route = useRoute()
   
   // 监听特定参数的变化并做出响应
   watch(() => route.params.id, (newId) => {
     fetchUserData(newId) // 重新请求数据
   })
   ```

2. **使用路由守卫 `onBeforeRouteUpdate`**：
   ```javascript
   import { onBeforeRouteUpdate } from 'vue-router'
   
   onBeforeRouteUpdate((to, from) => {
     // to.params.id 代表即将跳转到的新参数
     fetchUserData(to.params.id)
   })
   ```

3. **给 `<router-view>` 绑定 `key`**（简单粗暴但有性能损耗）：
   ```html
   <!-- 每次路由路径或参数改变时，都会销毁并重新创建组件，从而触发生命周期 -->
   <router-view :key="$route.fullPath" />
   ```
