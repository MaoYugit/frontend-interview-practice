### Vue3-slot

在 Vue 中，**Slot（插槽）** 是组件内容分发（Content Distribution）的 API。它允许我们在父组件中向子组件内部的特定位置传递 HTML 结构、组件或其他内容，从而大大增强了组件的灵活性和复用性。

简单来说，**子组件留出“空位”（占位符），父组件决定往这个“空位”里填入什么内容**。这就像是一个相框（子组件），相框的大小、边框样式是固定好的，但里面放什么照片（内容）由用户（父组件）决定。

---

### 一、 插槽的作用与核心价值

1. **提高组件的复用性与灵活性**
   在没有插槽之前，我们只能通过 `props` 向子组件传递基本类型或对象数据。如果想传递一段复杂的 HTML 结构甚至另一个组件，单靠 `props` 会非常困难。插槽允许我们将“结构”作为参数传递。
2. **实现内容与样式的解耦**
   子组件只需要负责整体的布局结构和内部逻辑（比如弹窗的显示/隐藏、按钮的点击事件），而具体的展示内容（比如弹窗里是一段文字、一个表单，还是一个图片列表）可以完全交由父组件决定。

---

### 二、 插槽的常见类型

Vue 中主要有三种插槽类型：**默认插槽**、**具名插槽**和**作用域插槽**。

#### 1. 默认插槽（Default Slot / 匿名插槽）
最基础的插槽。如果子组件中只有一个 `<slot>` 标签，且没有指定名字，父组件传入的所有未指定名字的内容都会被填入这个位置。

* **子组件 (`ChildComponent.vue`)**：
  ```html
  <template>
    <div class="card">
      <h3>卡片标题</h3>
      <!-- 插槽占位符，中间写的是默认备用内容 -->
      <slot>默认的卡片内容（当父组件未传递内容时显示）</slot>
    </div>
  </template>
  ```
* **父组件**：
  ```html
  <template>
    <ChildComponent>
      <p>这是由父组件传入的个性化内容。</p>
    </ChildComponent>
  </template>
  ```

#### 2. 具名插槽（Named Slot）
当子组件内部有多个地方需要由父组件动态填入内容时，可以通过 `name` 属性给插槽命名。父组件使用 `v-slot:插槽名`（简写为 `#插槽名`）来将内容分发到指定的插槽。

* **子组件 (`LayoutComponent.vue`)**：
  ```html
  <template>
    <div class="container">
      <header>
        <slot name="header"></slot>
      </header>
      <main>
        <!-- 未命名的插槽，其默认 name 为 "default" -->
        <slot></slot>
      </main>
      <footer>
        <slot name="footer"></slot>
      </footer>
    </div>
  </template>
  ```
* **父组件**：
  ```html
  <template>
    <LayoutComponent>
      <!-- 使用 v-slot 指令或其简写 # -->
      <template #header>
        <h1>这是头部内容</h1>
      </template>
  
      <!-- 默认插槽的内容可以不用包裹，也可以包裹在 #default 中 -->
      <p>这是主体内容部分。</p>
  
      <template #footer>
        <p>这是页脚内容</p>
      </template>
    </LayoutComponent>
  </template>
  ```

#### 3. 作用域插槽（Scoped Slot）
通常情况下，父组件模板中的内容是在父组件作用域中编译的，无法直接访问子组件内部的数据。如果**父组件既想自定义插槽的结构，又想使用子组件内部的数据**，就需要用到作用域插槽。

* **子组件 (`UserList.vue`)**：
  ```html
  <template>
    <ul>
      <li v-for="user in users" :key="user.id">
        <!-- 将子组件的数据通过绑定属性（如 :user）传递给插槽 -->
        <slot :user="user">{{ user.name }}</slot>
      </li>
    </ul>
  </template>
  
  <script setup>
  const users = [
    { id: 1, name: '张三', role: '管理员' },
    { id: 2, name: '李四', role: '普通用户' }
  ]
  </script>
  ```
* **父组件**：
  ```html
  <template>
    <UserList>
      <!-- 使用 v-slot="slotProps" 接收子组件传过来的所有属性 -->
      <template #default="slotProps">
        <span>{{ slotProps.user.name }} - 【{{ slotProps.user.role }}】</span>
      </template>
    </UserList>
  </template>
  ```
  *(注：父组件中也可以直接使用解构赋值写成 `#default="{ user }"`)*。

### 三、 常见应用场景

在实际业务开发或开源 UI 框架（如 Element Plus、Ant Design Vue）中，插槽几乎无处不在：

1. **通用布局组件**：如导航栏（Navbar）、侧边栏（Sidebar）、卡片（Card）、弹窗（Modal）等，这些组件的容器样式和基本逻辑是固定的，但里面的内容千变万化。
2. **列表/表格类组件**：如表格的“操作列”。表格组件（子组件）负责渲染行和列并管理数据，而父组件通过作用域插槽，可以在某一行自定义放置“编辑”、“删除”等按钮，并拿到当前行的数据。
3. **骨架屏（Skeleton）或加载占位图**：子组件在加载时显示骨架屏，加载完成后通过插槽展示真实内容。

### 四、 总结与注意事项（面试加分点）

* **编译作用域**：
  Vue 官方文档中有一条重要规则：“**父级模板里的所有内容都是在父级作用域中编译的；子级模板里的所有内容都是在子级作用域中编译的**。” 作用域插槽是打破这一编译边界、让父组件在自定义结构时能获取子组件临时数据的唯一官方途径。
* **插槽的本质**：
  在 Vue 3 中，插槽的本质是一个**返回虚拟 DOM（VNode）的函数**。子组件在渲染时，调用这个函数并传入参数（如果是作用域插槽），从而得到父组件分发的 VNode。这种函数式的设计使得 Vue 3 的插槽性能比 Vue 2 有了极大的提升，避免了不必要的父组件重新渲染。
