### Vue 的 template 标签有什么用？

我从三个主要用途来回答，它们都围绕着一个核心特性：**`<template>` 本身不会被渲染成任何真实的 DOM 元素**。

---

**一、条件/循环分组，避免多余的包装元素**

这是最常用的场景。当需要同时控制多个元素，又不想在 DOM 中多一层 `<div>` 时：

```html
<!-- 不想多包一层 div，破坏布局 -->
<template v-if="isReady">
  <h1>标题</h1>
  <p>这里是一段描述文字</p>
</template>
```

用 `<template>` 来承载 `v-if` 或 `v-for` 指令，既能分组控制多个节点，又保持最终的 DOM 结构干净。`v-show` 不能用在 `<template>` 上，因为 `v-show` 需要真实 DOM 元素来切换 `display` 属性。

---

**二、Vue 单文件组件中的模板定义**

在 `.vue` 文件里，`<template>` 标签是必需的容器，用来包裹整个组件的 HTML 模板：

```html
<template>
  <div class="wrapper">
    <h1>{{ title }}</h1>
    <p>{{ content }}</p>
  </div>
</template>
```

解析时 Vue Loader 会编译这个块内的内容，`<template>` 本身不进 DOM，只作为声明式的模板区块。

---

**三、配合 `v-slot` 定义插槽内容**

Vue 2.6+ 用 `v-slot` 语法时，必须写在 `<template>` 上，表示将指定内容分发到具名插槽或作用域插槽：

```html
<!-- 具名插槽 -->
<template v-slot:header>
  <h2>自定义头部</h2>
</template>

<!-- 作用域插槽，接收子组件传来的 slot props -->
<template v-slot:default="slotProps">
  <span>{{ slotProps.item.name }}</span>
</template>
```

这里的 `<template>` 作为插槽内容的逻辑容器，同样不会产生任何多余的 DOM 层级。

---

**总结一句话**

`<template>` 是 Vue 提供的“逻辑包裹元素”，专门用来承载指令和分组节点，自身不会渲染到 DOM 中，非常适合条件渲染分组、循环分组和插槽内容定义，保持 DOM 结构简洁。
