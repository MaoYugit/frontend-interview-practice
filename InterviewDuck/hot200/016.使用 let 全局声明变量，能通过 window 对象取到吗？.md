### 使用 let 全局声明变量，能通过 window 对象取到吗？

不能，在一个 `<script>` 中直接使用 `let` 全局声明变量，不能通过 `window` 对象取到。

我会分清楚区别、原因和内存存储位置来说。

**1. 现象上的区别**
```javascript
var a = 1;
let b = 2;
console.log(window.a); // 1
console.log(window.b); // undefined
```
`var` 声明的全局变量会成为 `window` 对象的属性，`let` 不会。

**2. 本质原因**
这跟 ES6 之后全局变量的存储机制有关。全局环境下的 `let/const` 声明虽然也是全局作用域，但它被记录在**全局环境记录中的声明式环境记录（declarative environment record）**里，而不是像 `var` 那样放在**对象式环境记录（object environment record）**中，而 `window` 对象恰好就是这个对象式环境记录。因此 `let` 声明的变量并不是 `window` 的属性。

**3. 是否还可以访问到？**
能，它仍然是一个合法的全局变量，只是不挂在 `window` 上。
```javascript
let b = 2;
console.log(b); // 2
```
用 `b` 直接访问毫无问题，它处于“全局块作用域”中，不会污染 `window`。

**总结一句话**
在全局用 `let` 声明的变量是真正的“非属性全局变量”，只存在于全局作用域内，不会成为 `window` 的属性，所以 `window.xxx` 取不到，但直接使用变量名仍然可以正常访问。
