### 如何判断 JavaScript 变量是数组？

我从可靠性、使用场景和原理递进着说，主要有四种方法。

---

**一、`Array.isArray()`（最推荐）**

这是 ES5 引入的标准方法，专门用来判断一个值是否为数组，不受跨执行环境影响。

```javascript
Array.isArray([]);              // true
Array.isArray({ length: 0 });  // false
Array.isArray(arguments);      // false
```

优点：简洁、可靠、语义明确，是目前的最佳实践。

---

**二、`instanceof` 操作符**

基于原型链判断，检查构造函数的 `prototype` 是否出现在对象的原型链上。

```javascript
[] instanceof Array;       // true
{} instanceof Array;       // false
```

**但有局限性**：在跨 `iframe` 或跨窗口环境中会失效，因为不同执行上下文有各自独立的 `Array` 构造函数，原型链无法匹配。而且通过 `Object.setPrototypeOf` 修改原型链也会干扰判断。

---

**三、`Object.prototype.toString.call()`**

利用 `Object.prototype.toString` 返回内部属性 `[[Class]]` 的特性。

```javascript
Object.prototype.toString.call([]);       // '[object Array]'
Object.prototype.toString.call({});       // '[object Object]'
Object.prototype.toString.call(null);     // '[object Null]'
```

优点是不受跨执行环境影响，ES5 之前也很常用。缺点是比较冗长，而且 `Symbol.toStringTag` 可以伪造结果。

---

**四、检查构造函数 `constructor` 属性**

```javascript
[].constructor === Array; // true
```

同样有跨执行环境问题和原型修改风险，不推荐用于严肃的类型判断。

---

**总结：**

| 方法              | 可靠性 | 跨 iframe | 推荐度   |
| ----------------- | ------ | --------- | -------- |
| `Array.isArray()` | 最高   | ✅         | 首选     |
| `instanceof`      | 一般   | ❌         | 次选     |
| `toString`        | 较高   | ✅         | 兜底方案 |
| `constructor`     | 较低   | ❌         | 不推荐   |

实际开发中直接用 `Array.isArray()` 就够了，既准确又语义化。如果面试官问到兼容老旧环境，可以补充说明以前用 `Object.prototype.toString.call()` 做 polyfill。
