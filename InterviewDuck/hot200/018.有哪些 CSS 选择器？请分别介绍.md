### 有哪些 CSS 选择器？请分别介绍

好的，这个问题我从基础到高级，分层来回答。

---

**一、基础选择器**

- **元素选择器**：直接选标签，如 `p { }`，选中所有 `<p>` 元素。
- **类选择器**：`.classname { }`，选中所有带该 class 的元素，可复用。
- **ID 选择器**：`#idname { }`，选中唯一 ID 元素，一个页面中 ID 应唯一。
- **通配选择器**：`* { }`，选中所有元素，常用于重置样式，但性能较差。

---

**二、属性选择器**

根据元素属性及属性值匹配：

- `[attr]` —— 有该属性即可
- `[attr="val"]` —— 属性值完全匹配
- `[attr^="val"]` —— 以某值开头
- `[attr$="val"]` —— 以某值结尾
- `[attr*="val"]` —— 包含某值
- `[attr~="val"]` —— 包含独立单词（空格分隔）

---

**三、组合选择器**

- **后代选择器**：`div p { }`，选中 div 内所有后代 p，无论嵌套多深。
- **子代选择器**：`div > p { }`，只选直接子元素。
- **相邻兄弟选择器**：`h1 + p { }`，选紧接在 h1 后的第一个 p 兄弟。
- **通用兄弟选择器**：`h1 ~ p { }`，选 h1 后所有同级 p 兄弟。
- **分组选择器**：`h1, h2, p { }`，多个选择器共用样式。

---

**四、伪类选择器**

用于定义元素的特殊状态：

- **动态伪类**：`:hover`、`:active`、`:focus`、`:visited`
- **结构伪类**：
  - `:first-child`、`:last-child`、`:only-child`
  - `:nth-child(n)`、`:nth-last-child(n)`
  - `:first-of-type`、`:last-of-type`、`:nth-of-type(n)`
- **表单相关**：`:checked`、`:disabled`、`:enabled`、`:required`、`:valid`、`:invalid`
- **其他**：`:not(selector)` 排除选择器；`:root` 选根元素；`:empty` 选无子节点的元素

---

**五、伪元素选择器**

用于选中元素的特定部分，创建“虚拟”元素：

- `::before` —— 在元素内容前插入内容
- `::after` —— 在元素内容后插入内容
- `::first-line` —— 文本首行
- `::first-letter` —— 首字母
- `::placeholder` —— 输入框占位文本样式
- `::selection` —— 用户选中文本的样式

注意：伪元素用双冒号是 CSS3 规范，早期 `:before` 单冒号为兼容写法。

---

**补充：选择器优先级**

如果面试官追问，可以这样回答：

优先级计算（a, b, c, d）：
- 行内样式：a=1
- ID 选择器：b 计数
- 类、属性、伪类：c 计数
- 元素、伪元素：d 计数

`!important` 优先级最高，但不建议滥用，会破坏样式层的可维护性。
