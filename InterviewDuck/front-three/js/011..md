JavaScript 中 || 和 && 操作符的返回值是什么？

在 JavaScript 中，逻辑双竖线 `||`（逻辑或）和双和号 `&&`（逻辑与）操作符的返回值有一个非常重要的特点：**它们并不一定会返回布尔值（`true` 或 `false`），而是返回两个操作数中的某一个原始值。**

这一机制被称为**短路求值（Short-circuit Evaluation）**。

---

### 1. `||`（逻辑或）的返回值规则

`||` 操作符从左到右依次计算操作数：

1. **如果左侧的操作数是真值（Truthy）**，则直接返回**左侧操作数的值**（此时右侧的代码不会被执行/求值）。
2. **如果左侧的操作数是假值（Falsy）**，则返回**右侧操作数的值**。

**示例：**

```javascript
"Alice" || "Bob"; // 返回 "Alice" （"Alice" 是真值，直接返回，短路）
"" || "Bob"; // 返回 "Bob"   （"" 是假值，返回右侧）
0 || 42; // 返回 42      （0 是假值，返回右侧）
false || null; // 返回 null    （false 是假值，返回右侧，哪怕右侧也是假值）
```

**常见应用场景：提供默认值**

```javascript
function greet(name) {
  // 如果没有传入 name（即 undefined，是假值），则使用默认值 "Guest"
  const userName = name || "Guest";
  console.log("Hello, " + userName);
}
```

_(注：由于 `0` 和 `""` 也是假值，使用 `||` 设置默认值时可能会误伤它们。在 ES2020 中引入了空值合并操作符 `??` 来更精确地处理这个问题。)_

---

### 2. `&&`（逻辑与）的返回值规则

`&&` 操作符同样从左到右依次计算操作数：

1. **如果左侧的操作数是假值（Falsy）**，则直接返回**左侧操作数的值**（此时右侧的代码不会被执行/求值）。
2. **如果左侧的操作数是真值（Truthy）**，则返回**右侧操作数的值**。

**示例：**

```javascript
"Alice" && "Bob"; // 返回 "Bob"   （"Alice" 是真值，继续向右，返回右侧）
"" && "Bob"; // 返回 ""      （"" 是假值，直接返回，短路）
0 && 42; // 返回 0       （0 是假值，直接返回，短路）
true && null; // 返回 null    （true 是真值，继续向右，返回右侧）
```

**常见应用场景：安全链式调用或条件执行**

```javascript
// 场景 1：防止读取 null 或 undefined 的属性时报错
const user = null;
const name = user && user.name; // 返回 null，而不会报错（如果直接写 user.name 会报错）

// 场景 2：React 等框架中常用的条件渲染
{
  isLoggedIn && <Dashboard />;
} // 如果未登录（isLoggedIn 为 false），则短路，不渲染组件
```

---

### 3. 规则总结

| 操作符         | 左侧为 Truthy（真值）      | 左侧为 Falsy（假值）       |
| :------------- | :------------------------- | :------------------------- |
| **`A \|\| B`** | **返回 `A`**（不执行 `B`） | **返回 `B`**               |
| **`A && B`**   | **返回 `B`**               | **返回 `A`**（不执行 `B`） |

在 `if` 语句等需要布尔值的地方，JavaScript 会把 `||` 或 `&&` 返回的具体值隐式地转换为布尔值，因此看起来像是在进行纯粹的逻辑布尔运算。例如：

```javascript
if ("Alice" || "Bob") { ... }
// 实际上先计算 "Alice" || "Bob" 得到 "Alice"
// 然后 if 将 "Alice" 隐式转换为 true 执行判断
```
