JavaScript 中 null 和 undefined 的区别是什么？

在 JavaScript 中，`null` 和 `undefined` 都表示“无”或“空”的值，但它们在语义、数据类型、数值转换以及使用场景上有着明确的区别。

---

### 1. 概念与语义的区别

- **`undefined`（未定义）**：表示**“缺少值”**。意味着这里应该有一个值，但目前还没有被定义或赋值。这通常是系统自动赋予的默认状态。
- **`null`（空值）**：表示**“没有对象”**。意味着这里本该是一个对象，但现在是空的。这通常是开发者**主动、有意**设置的，用来表示一个空值。

---

### 2. 数据类型与 `typeof` 的返回值

两者虽然都属于 JavaScript 的原始数据类型，但 `typeof` 的检测结果不同：

- `typeof undefined` 返回 **`"undefined"`**。
- `typeof null` 返回 **`"object"`**。
  - _注：这是 JavaScript 的一个历史遗留 Bug。在 JS 最初的设计中，值是由一个表示类型的标签和实际数据值组成的。对象的类型标签是 `0`，而 `null` 代表空指针（其二进制全为 0），因此 `typeof null` 错误地返回了 `"object"`。为了兼容老代码，这个表现被保留至今。_

---

### 3. 数值转换（Math Context）

当尝试将它们转换为数字进行数学计算时：

- **`undefined` 转换为 `NaN`（Not a Number）**。因为未定义的值无法进行具体的数值运算。
  ```javascript
  Number(undefined); // NaN
  10 + undefined; // NaN
  ```
- **`null` 转换为 `0`**。因为“空”在数学概念中可以被量化为“没有（即 0）”。
  ```javascript
  Number(null); // 0
  10 + null; // 10
  ```

---

### 4. 比较运算

- **宽松相等（`==`）**：返回 `true`。因为在进行隐式类型转换时，它们都被视作“空值”。
- **严格相等（`===`）**：返回 `false`。因为它们的类型不同（一个是 Undefined，一个是 Null）。
  ```javascript
  null == undefined; // true
  null === undefined; // false
  ```

---

### 5. 典型使用场景

#### 什么时候会出现 `undefined`？（多为系统自动行为）

1.  **声明了变量但未初始化（未赋值）时**：
    ```javascript
    let a;
    console.log(a); // undefined
    ```
2.  **调用函数时，应该提供的参数没有提供**：
    ```javascript
    function greet(name) {
      console.log("Hello " + name);
    }
    greet(); // Hello undefined（未传参，name 为 undefined）
    ```
3.  **访问对象不存在的属性或数组不存在的索引**：
    ```javascript
    const obj = {};
    console.log(obj.age); // undefined
    ```
4.  **函数没有明确的 `return` 语句时，默认返回 `undefined`**。

#### 什么时候应该使用 `null`？（多为开发者主动行为）

1.  **作为对象占位符**：当你声明一个变量，已知它未来会存放一个对象，但目前对象还没创建好时，可以初始化为 `null`。
    ```javascript
    let currentUser = null; // 表示目前没有登录用户
    ```
2.  **释放内存 / 清空引用**：当一个大对象不再需要使用时，可以将其显式赋值为 `null`，以便垃圾回收机制（GC）后续回收。
    ```javascript
    let largeData = {
      /* 很多数据 */
    };
    // 使用完毕后
    largeData = null; // 切断引用
    ```
3.  **作为原型链的终点**：在原型链中，`Object.prototype.__proto__` 的值是 `null`，这代表原型链的尽头。

---

### 总结

简单来说，**`undefined` 是系统级别的、非预期的、未初始化的状态**；而 **`null` 是用户级别的、预期的、主动设置的空对象引用**。
