typeof 和 instanceof 有什么区别？

在 JavaScript 中，`typeof` 和 `instanceof` 是两种最常用的类型检测手段，但它们的工作原理、返回值以及适用场景有着本质的区别。

---

### 1. typeof 运算符

`typeof` 是一个一元运算符，用于获取一个变量或表达式的**基础数据类型**。

- **返回值**：一个表示类型的**小写字符串**（如 `"string"`、`"number"` 等）。
- **适用对象**：最适合用来判断**原始类型**（如 String, Number, Boolean, Symbol, BigInt, Undefined）以及 **Function**。
- **局限性**：
  - 无法区分具体的对象类型（如数组、正则、日期、普通对象），它们都会返回 `"object"`。
  - 对于 `null`，会返回 `"object"`（历史遗留 Bug）。

#### 示例：

```javascript
typeof "hello"; // "string"
typeof 123; // "number"
typeof true; // "boolean"
typeof undefined; // "undefined"
typeof Symbol(); // "symbol"
typeof 10n; // "bigint"
typeof function () {}; // "function"

// 局限性体现：
typeof null; // "object"
typeof []; // "object" （无法识别是数组）
typeof {}; // "object"
typeof new Date(); // "object"
```

---

### 2. instanceof 运算符

`instanceof` 是一个二元运算符，用于检测构造函数的 `prototype` 属性是否出现在某个实例对象的**原型链**上。

- **语法**：`object instanceof constructor`
- **返回值**：**布尔值**（`true` 或 `false`）。
- **适用对象**：适合用来检测**引用类型**的具体类型（如 Array, Date, RegExp，或者自定义的类/构造函数实例）。
- **局限性**：
  - **无法检测字面量形式的原始类型**（因为原始类型没有原型链）。
  - 在多全局环境（如 `iframe`）下可能会失效，因为不同 `iframe` 拥有独立的全局环境和构造函数。

#### 示例：

```javascript
const arr = [1, 2, 3];
arr instanceof Array; // true （判断是否为数组）
arr instanceof Object; // true （Array 继承自 Object）

const date = new Date();
date instanceof Date; // true

// 局限性体现（无法判断原始类型）：
"hello" instanceof String; // false （字面量不是对象实例）
new String("hello") instanceof String; // true  （包装对象实例可以检测）
```

---

### 3. 核心区别对比

| 维度                 | `typeof`                                                   | `instanceof`                                                                    |
| :------------------- | :--------------------------------------------------------- | :------------------------------------------------------------------------------ |
| **工作原理**         | 基于变量在底层的机器码标记（前三位二进制）来直接快速判定。 | 沿着对象的原型链（`__proto__`）向上查找，看是否能匹配到构造函数的 `prototype`。 |
| **返回值**           | **字符串**（如 `"number"`, `"object"` 等）                 | **布尔值**（`true` 或 `false`）                                                 |
| **最适场景**         | 判断**原始类型**和**函数**（Function）。                   | 判断**引用对象**的具体子类型或自定义类的实例。                                  |
| **对原始类型的检测** | 完美支持（除了 `null` ）。                                 | 不支持（字面量形式返回 `false`）。                                              |
| **对引用的检测**     | 只能粗略判断为 `"object"` 或 `"function"`。                | 可以精确区分 `Array`、`Date`、`RegExp` 等。                                     |

---

### 4. 补充：如果两者都无法满足需求怎么办？

因为 `typeof` 无法区分 `null`、数组和普通对象，而 `instanceof` 又无法检测原始类型且在跨 iframe 时有局限，所以在需要**绝对高精度类型判断**的场景下，业界通常使用以下方法：

#### **`Object.prototype.toString.call(value)`**

这个方法利用了 Object 的原型方法，它会统一返回一个格式为 `"[object Type]"` 的字符串，可以完美区分 JavaScript 中的所有内置类型：

```javascript
Object.prototype.toString.call("hello"); // "[object String]"
Object.prototype.toString.call(123); // "[object Number]"
Object.prototype.toString.call(null); // "[object Null]"
Object.prototype.toString.call(undefined); // "[object Undefined]"
Object.prototype.toString.call([]); // "[object Array]"
Object.prototype.toString.call(new Date()); // "[object Date]"
Object.prototype.toString.call(function () {}); // "[object Function]"
```
