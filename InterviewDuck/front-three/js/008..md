JavaScript 其他值到字符串的转换规则是什么？

在 JavaScript 中，将其他类型的值转换为字符串（String）是由 ECMAScript 规范内部的 **`ToString` 抽象操作**控制的。无论是通过**显式转换**（如 `String(value)`）还是**隐式转换**（如 `value + ""`），都遵循一套确定的规则。

这些转换规则可以分为**原始类型**和**对象类型**两大类：

---

### 1. 原始类型的转换规则

对于原始值（Primitives），转换规则相对直接：

| 原始值      | 转换后的字符串结果   | 备注与特例                                                                                                                                                                                                               |
| :---------- | :------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `undefined` | `"undefined"`        |                                                                                                                                                                                                                          |
| `null`      | `"null"`             |                                                                                                                                                                                                                          |
| `true`      | `"true"`             |                                                                                                                                                                                                                          |
| `false`     | `"false"`            |                                                                                                                                                                                                                          |
| **Number**  | 对应数字的字符串形式 | 包含以下几个特例：<br>• `0` 和 `-0` 都会转换为 `"0"`<br>• `NaN` 转换为 `"NaN"`<br>• `Infinity` / `-Infinity` 转换为 `"Infinity"` / `"-Infinity"`<br>• 极大或极小的数字会转换为科学计数法形式（如 `1e21` 变为 `"1e+21"`） |
| **BigInt**  | 对应数字的字符串形式 | 会去掉末尾的 `n`（例如 `10n` 转换为 `"10"`）                                                                                                                                                                             |
| **Symbol**  | —                    | **不能进行隐式转换**，只能进行显式转换（详见下文说明）                                                                                                                                                                   |

#### ⚠️ 关于 Symbol 的特殊限制

为了防止在无意中将 Symbol 当作普通字符串处理，JavaScript 规定 **Symbol 类型不能进行隐式字符串转换**。如果尝试通过 `+ ""` 或模板字面量连接 Symbol，会抛出 `TypeError`：

```javascript
const sym = Symbol("foo");

// ❌ 隐式转换会报错
const str1 = sym + ""; // TypeError: Cannot convert a Symbol value to a string
const str2 = `${sym}`; // TypeError: Cannot convert a Symbol value to a string

//  显式转换可以成功
const str3 = String(sym); // "Symbol(foo)"
const str4 = sym.toString(); // "Symbol(foo)"
```

---

### 2. 对象类型的转换规则（ToPrimitive）

当尝试将一个对象（如普通对象、数组、函数等）转换为字符串时，JavaScript 会先通过内部的 **`ToPrimitive(hint: "string")`** 操作将其转换为原始值，然后再将该原始值转换为字符串。

对于 `hint: "string"`，其转换步骤如下：

1. 优先调用对象的 **`toString()`** 方法。如果它返回一个原始值（如字符串、数字或布尔值），则将该原始值转换为字符串并返回。
2. 如果 `toString()` 没有返回原始值，则调用 **`valueOf()`** 方法。如果它返回一个原始值，则将其转换为字符串并返回。
3. 如果两个方法都没有返回原始值，则抛出 `TypeError`。

基于此规则，常见对象的转换结果如下：

#### ① 普通对象（Plain Object）

标准对象的 `toString()` 方法继承自 `Object.prototype`，默认返回类型标签：

```javascript
const obj = { name: "Alice" };
String(obj); // "[object Object]"
```

#### ② 数组（Array）

数组的 `toString()` 方法经过了重写。它会将数组的每个元素转换为字符串，并用逗号 `,` 连接起来（类似于调用不带参数的 `join()`）：

```javascript
String([]); // "" （空数组转换为空字符串）
String([1, 2, 3]); // "1,2,3"
String([[1, 2], 3]); // "1,2,3" （嵌套数组会被扁平化）
String([null, undefined]); // "," （数组中的 null 和 undefined 会被视为空字符串处理）
```

#### ③ 函数（Function）

函数的 `toString()` 会返回该函数的源代码文本：

```javascript
function test() {
  return 1;
}
String(test); // "function test() { return 1; }"
```

#### ④ 日期（Date）

`Date` 对象的 `ToPrimitive` 默认行为与普通对象不同（它默认优先调用 `toString` 而非 `valueOf`），其转换结果为一个代表本地时间的易读字符串：

```javascript
String(new Date()); // "Tue Jun 16 2026 15:28:00 GMT+0800 (中国标准时间)"
```

### 3. 触发字符串转换的常见场景

在日常开发中，主要通过以下两种方式触发这些转换规则：

#### 显式转换（Explicit）

- **`String(value)`**：最为推荐的安全写法。它能处理所有类型（包括 `null`、`undefined` 和 `Symbol`），且不依赖对象自身的方法。
- **`value.toString()`**：调用对象上的原生方法。**注意**：`null` 和 `undefined` 没有该方法，调用时会报错（`TypeError: Cannot read properties of null`）。

#### 隐式转换（Implicit）

- **加号 `+` 运算符**：如果 `+` 的其中一个操作数是字符串，JavaScript 会将另一个操作数也转换为字符串并进行拼接：
  ```javascript
  1 + "2"; // "12"
  true + "ok"; // "trueok"
  ```
- **模板字面量**：在 ` `${value}` ` 内部，JavaScript 会自动对插值表达式进行字符串转换（Symbol 除外）。
