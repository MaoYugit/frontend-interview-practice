JavaScript 其他值到布尔值的转换规则是什么？

在 JavaScript 中，将其他类型的值转换为布尔值（Boolean）是所有类型转换中最简单、最确定的一种。它由 ECMAScript 规范内部的 **`ToBoolean` 抽象操作**控制。

JavaScript 中的所有值都可以被分为两类：**假值（Falsy）**和**真值（Truthy）**。转换规则非常简单：**只有少数特定的值会被转换为 `false`，而其他所有值都会被转换为 `true`。**

---

### 1. 假值（Falsy 值）：转换后为 `false`

在 JavaScript 中，**只有以下 8 个值**在转换为布尔值时会变成 `false`：

| 假值                    | 类型      | 说明                   |
| :---------------------- | :-------- | :--------------------- |
| `false`                 | Boolean   | 布尔值自身             |
| `undefined`             | Undefined | 未定义                 |
| `null`                  | Null      | 空值                   |
| `0`                     | Number    | 数字 0                 |
| `-0`                    | Number    | 数字 -0                |
| `0n`                    | BigInt    | BigInt 类型的 0        |
| `NaN`                   | Number    | 非数值（Not a Number） |
| `""`（或 `''`, ` `` `） | String    | 空字符串               |

> 💡 **历史遗留的特例**：在浏览器环境中，由于历史兼容性原因，非标准的宿主对象 `document.all` 也会被当作假值处理，转换为 `false`。除此之外，没有任何其他对象会被转换为 `false`。

---

### 2. 真值（Truthy 值）：转换后为 `true`

**除了上述的假值之外，JavaScript 中的所有其他值转换为布尔值时都是 `true`。**

这里有几个开发中极易混淆的**常见真值**（很多人会误以为它们是假值）：

- **空对象和空数组**：
  - `[]`（空数组） $\rightarrow$ **`true`**
  - `{}`（空对象） $\rightarrow$ **`true`**
  - `function() {}`（空函数） $\rightarrow$ **`true`**
    _(在 JavaScript 中，所有对象/引用类型，无论是否为空，一律转换为 `true`)_
- **包含非空内容的“假值形式”字符串**：
  - `"0"`（含有字符 0 的字符串） $\rightarrow$ **`true`**
  - `"false"`（字面量为 false 的字符串） $\rightarrow$ **`true`**
  - `" "`（仅包含空格的非空字符串） $\rightarrow$ **`true`**
- **其他数值**：
  - 所有非 `0` 数字（如 `-1`、`3.14`） $\rightarrow$ **`true`**
- **Symbol 对象**：
  - `Symbol()` $\rightarrow$ **`true`**

---

### 3. 触发布尔值转换的常见场景

#### 显式转换（Explicit）

- **`Boolean(value)`**：直接调用包装函数。
- **`!!value`（双重非操作符）**：最常用的简写技巧。第一个 `!` 将值转换为其相反的布尔值，第二个 `!` 再次取反，从而得到该值原本对应的布尔值。
  ```javascript
  const hasUser = !!"Alice"; // true
  const isEmpty = !!0; // false
  ```

#### 隐式转换（Implicit）

在需要条件判断的上下文中，JavaScript 会自动将表达式的值转换为布尔值：

- **条件语句**：`if (condition)` 或 `while (condition)`。
- **三元运算符**：`condition ? expr1 : expr2`。
- **逻辑运算符**：
  - 逻辑非 `!` 会对其操作数进行布尔转换并取反。
  - 逻辑与 `&&` 和逻辑或 `||` 在运行过程中，会通过计算子表达式的布尔值来决定“短路”行为（但注意：它们返回的是**最后求值的那个表达式的原始值**，而不仅是布尔值本身）。
    ```javascript
    const name = "Alice" || ""; // 返回 "Alice" 而不是 true
    ```
