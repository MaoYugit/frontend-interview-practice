JavaScript 其他值到数字值的转换规则是什么？
在 JavaScript 中，将其他类型的值转换为数字值（Number）是由 ECMAScript 规范内部的 **`ToNumber` 抽象操作**控制的。无论是显式转换还是隐式转换，都会遵循一套严格的转换规则。

我们可以将其分为**原始类型**和**对象类型**两大类进行说明：

---

### 1. 原始类型的转换规则

对于原始值，其转换规则及特殊处理如下表：

| 原始值      | 转换后的数字结果          | 备注与特例                                                                                                                                                                                                                                                                                     |
| :---------- | :------------------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `undefined` | `NaN`                     |                                                                                                                                                                                                                                                                                                |
| `null`      | `0`                       |                                                                                                                                                                                                                                                                                                |
| `true`      | `1`                       |                                                                                                                                                                                                                                                                                                |
| `false`     | `0`                       |                                                                                                                                                                                                                                                                                                |
| **Symbol**  | —                         | **抛出 `TypeError`**。Symbol 无法隐式或显式地转为数字。                                                                                                                                                                                                                                        |
| **BigInt**  | 对应数值（或 `NaN`/抛错） | • **显式转换成功**：`Number(10n)` 得到 `10`（若数值超出安全范围会丢失精度）。<br>• **隐式转换抛错**：出于安全考虑，禁止对 BigInt 进行隐式数字转换（如 `+10n` 会抛出 `TypeError`）。                                                                                                            |
| **String**  | 视内容而定                | • **空字符串或仅含空格的字符串**：转换为 `0`（例如 `""`、`"  "`、`"\n"` 均转为 `0`）。<br>• **有效数字格式**：转换为对应的数字（支持十六进制 `0x`、二进制 `0b`、八进制 `0o` 以及科学计数法 `1e3` 等）。<br>• **无效数字格式**：只要含有非数字字符，即转换为 `NaN`（例如 `"123a"`、`"abc"` ）。 |

---

### 2. 对象类型的转换规则（ToPrimitive）

当尝试将一个对象转换为数字时，JavaScript 会通过内部的 **`ToPrimitive(hint: "number")`** 操作将其先转换为原始值，然后再将原始值转为数字。

其内部转换步骤如下：

1. 优先调用对象的 **`valueOf()`** 方法。如果它返回一个原始值，则直接将该原始值转为数字并返回。
2. 如果 `valueOf()` 返回的不是原始值，则调用 **`toString()`** 方法。如果它返回一个原始值，则将其转为数字并返回。
3. 如果两个方法都没有返回原始值，则抛出 `TypeError`。

基于此规则，常见对象的数字转换结果如下：

#### ① 普通对象（Plain Object）

普通对象的 `valueOf()` 返回其自身（不是原始值），进而调用 `toString()` 得到 `"[object Object]"`，这是一个无效数字格式的字符串，所以转换结果为 `NaN`：

```javascript
Number({}); // NaN
```

#### ② 数组（Array）

数组的 `valueOf()` 也返回自身，进而调用其自定义的 `toString()`：

- **空数组** `[]`：`toString()` 得到空字符串 `""`，再转换为数字得到 **`0`**。
- **仅含一个数字元素的数组** `[10]`：`toString()` 得到字符串 `"10"`，再转换为数字得到 **`10`**。
- **含多个元素的数组** `[1, 2]`：`toString()` 得到 `"1,2"`，由于含有逗号，属于无效数字字符串，因此转换为 **`NaN`**。

```javascript
Number([]); // 0
Number([10]); // 10
Number([1, 2]); // NaN
```

#### ③ 日期对象（Date）

`Date` 对象的 `valueOf()` 方法被重写过，会直接返回该日期对应的毫秒时间戳（数值类型），因此可以成功直接转换：

```javascript
Number(new Date()); // 得到对应的毫秒数时间戳，例如 1781595000000
```

### 3. 触发数字转换的常见场景

#### 显式转换（Explicit）

- **`Number(value)`**：最标准的强制转换方法，遵循以上完整的 `ToNumber` 规则。
- **`parseInt(value, radix)` / `parseFloat(value)`**：
  - **特殊点**：它们的解析规则与 `Number()` **不同**。它们专门用于解析字符串，会从左到右尽可能多地解析有效数字字符（例如 `parseInt("123px")` 会得到 `123`，而 `Number("123px")` 会得到 `NaN`）。

#### 隐式转换（Implicit）

以下操作符在计算前会将操作数隐式转为数字：

- **一元加/减操作符**：`+value`（常用的快捷转数字手段）或 `-value`。
- **非加号数学运算符**：减法 `-`、乘法 `*`、除法 `/`、取模 `%`（例如 `"5" - 2` 得到 `3`）。
- **位运算符**：`|`、`&`、`^`、`~`、`>>`、`<<`（例如 `"5" | 0` 得到 `5`）。
- **部分比较运算符**：与数字进行 `>`, `<`, `>=`, `<=` 比较时，另一侧的值会被转为数字后再行比较。
