**对于 React 生命周期，我通常会从**类组件**和**现代函数组件**两个维度去回答。它们的本质都是为了在组件的**挂载、更新和卸载**三个阶段去执行特定的逻辑。**

**首先，在传统的**类组件**中：**

- **挂载阶段**：最核心的是 **componentDidMount**，我们一般在这里发送网络请求或进行 DOM 操作。
- **更新阶段**：最常用的是 **shouldComponentUpdate**（用来做性能优化，决定组件是否重绘）和 **componentDidUpdate**。
- **卸载阶段**：在 **componentWillUnmount** **里去清除定时器、解绑事件，防止内存泄漏。**

**其次，在现在的**函数组件**中：**
我们不再使用这些繁琐的生命周期方法，而是统一使用 **useEffect** **这个 Hook 来模拟：**

- **传空数组** **[]**，就相当于 **componentDidMount**；
- **传入依赖项** **[dep]**，就相当于 **componentDidUpdate**；
- **在** **useEffect** **里返回一个清理函数（cleanup），就模拟了** **componentWillUnmount**。

**另外补充一点：React 自从引入了 Fiber 异步渲染架构后，废弃了之前带有** **componentWill** **的旧生命周期（因为它们可能会被多次触发），全面推荐我们使用 Hooks 来编写组件。”**
