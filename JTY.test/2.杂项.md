### 1. WeakSet 和 Set 的区别

- **Set**：
  - **值类型**：可以存储任意类型的值（原始值或对象）。
  - **引用类型**：对存储的对象是**强引用**。只要 Set 实例存在，其中的对象就不会被垃圾回收。
  - **可遍历性**：可遍历（支持 `forEach`、`for...of`），拥有 `size` 属性。
- **WeakSet**：
  - **值类型**：**只能存储对象**（或部分特定 Symbol），不能存储原始值。
  - **引用类型**：对存储的对象是**弱引用**。如果对象没有其他强引用，垃圾回收机制（GC）会自动回收该对象，WeakSet 中的对应项也会自动消失。
  - **可遍历性**：不可遍历，没有 `size` 属性，没有 `clear()` 方法。常用于存储 DOM 节点或检测循环引用，防止内存泄漏。

### 2. Array.prototype.groupBy() 和 Object.groupBy()

- **历史背景**：
  - 最初的提案确实曾考虑将分组功能设计为数组原型方法 `Array.prototype.group()`。但由于与某些旧的第三方库（如 Sugar.js）存在命名冲突（Web 兼容性问题），最终被修改为静态方法。
- **Object.groupBy()（已正式入标准）**：
  - 这是一个**静态方法**，用于对可迭代对象（如数组）进行分组。
  - **用法**：`Object.groupBy(iterable, callbackFn)`。
  - **返回值**：返回一个**无原型（null-prototype）的对象**，其中的属性键是回调函数返回的字符串，属性值是包含分组元素的数组。

### 3. `<script defer>` 标签的作用

- **异步下载**：在 HTML 解析的同时，带有 `defer` 的脚本会在后台异步下载，**不会阻塞**页面的 HTML 解析。
- **延迟执行**：脚本下载完毕后不会立即执行，而是等到**整个 HTML 解析完毕**、在 `DOMContentLoaded` 事件触发之前依次执行。
- **顺序保证**：如果页面有多个 `defer` 脚本，浏览器会严格按照它们在 HTML 中**出现的先后顺序**依次执行（而 `async` 无法保证顺序，下载完即刻执行）。

### 4. 怎么清除浮动？

- **原因**：子元素浮动后脱离了普通文档流，导致父元素高度塌陷，影响后续元素的排版。
- **常用方法**：
  1. **BFC 触发（最常用）**：给父元素设置 `overflow: hidden;` 或 `overflow: auto;`。
  2. **双伪元素清除法（最优雅）**：给父元素添加清除浮动的类名。
     ```css
     .clearfix::after {
       content: "";
       display: table;
       clear: both;
     }
     ```
  3. **额外标签法**：在父元素内容的末尾添加一个空的块级标签（如 `<div style="clear:both;"></div>`），但这样会增加无意义的 DOM 节点，不推荐。

### 5. React `useEffect` 第二个参数“空”会发生什么？

“空”在 React 中通常有两种不同的情况，行为截然不同：

- **情况 A：完全不传第二个参数（不写数组）**
  - **表现**：每次组件渲染（包括首次挂载以及之后的**每一次更新渲染**）后，副作用函数都会执行。这通常极易导致性能问题或无限循环。
- **情况 B：传空数组 `[]`**
  - **表现**：副作用函数**只在组件首次挂载（Mount）完成后执行一次**，其返回的清除函数（Cleanup）也只在组件卸载（Unmount）时执行一次。适用于初始化请求或事件绑定。

### 6. `<datalist>` 标签的作用

- **作用**：用于为 `<input>` 元素提供一个包含“预定义输入建议”的下拉列表。
- **用法**：通过 `<datalist id="xxx">` 定义列表项，并让 `<input list="xxx">` 关联该 ID。
- **效果**：它不像 `<select>` 那样限制用户只能选已有选项。用户可以自由输入任何内容，也可以在输入时看到匹配的建议项，常用于搜索框的输入联想。

### 7. Vue 3 响应式：ref, reactive, computed, watch 的作用

- **ref**：
  - 用于定义**基本数据类型**（如 String、Number）或**单对象**的响应式。
  - 在 JS 中需要通过 `.value` 进行读写，在模板（template）中会自动解包。
- **reactive**：
  - 用于定义**复杂数据类型**（如对象、数组）的响应式。
  - 不需要 `.value`，直接通过属性访问。底层基于 ES6 Proxy 代理整个对象。
- **computed**：
  - 计算属性。基于已有的响应式数据计算出新的响应式数据。
  - 拥有**缓存机制**，只有当其依赖的响应式数据发生改变时才会重新计算，性能优于直接写方法。
- **watch**：
  - 侦听器。用于监听特定响应式数据的变化，并在数据变化时执行自定义的**副作用回调**（如异步请求、本地存储、DOM 操作）。

### 8. WeakMap 和 Map 的区别

- **Map**：
  - **键的类型**：键可以是任意类型（包括对象、原始值、函数等）。
  - **引用机制**：对键是**强引用**。只要 Map 实例还在，即使外部没有其他引用，作为键的对象也不会被垃圾回收，容易导致内存泄漏。
  - **特性**：可遍历，拥有 `size` 属性。
- **WeakMap**：
  - **键的类型**：键**只能是对象**（或部分特定 Symbol）。
  - **引用机制**：对键是**弱引用**。如果作为键的对象在外部没有其他强引用存在，垃圾回收机制会自动回收该对象并清除 WeakMap 中对应的键值对。
  - **特性**：不可遍历，没有 `size` 属性，没有 `clear()` 方法。常用于关联 DOM 节点存储元数据、私有属性以及缓存。
