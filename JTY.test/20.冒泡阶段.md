你听到的**“冒泡阶段”（Bubbling Phase）**，是前端开发中非常核心、面试高频，且跟我们日常写交互息息相关的 **“DOM 事件传播机制”**。

不用担心，这个概念其实非常形象。我们可以用一个生活中的比喻来理解它。

---

### 一、 什么是“冒泡”？（形象比喻）

想象一下，你把一根吸管插到水杯底部吹气，气泡会从**水底（最深处）**产生，然后一步步**往上升**，直到升到**水面**。

在网页中，DOM 结构就像水杯：

- **最深处**：你具体点击、操作的那个最内层的标签（比如一个 `<span>` 或 `<button>`）。
- **水面**：最外层的 `<body>`、`<html>` 甚至是整个窗口 `window`。

当你在一个最内层的按钮上触发了 `click`（点击）或 `keydown`（按键）事件时，浏览器不仅会触发这个按钮绑定的事件，还会**把这个事件像气泡一样，一级一级往父元素上传递**，直到传到最外层。这个向上传递的过程，就叫**冒泡阶段**。

---

### 二、 事件传播的三阶段（整体背景）

为了让你更清楚整体概念，浏览器在处理一个事件（比如你在网页中央点了一下鼠标）时，其实经历了三个阶段：

1. **捕获阶段（Capture Phase）**：事件从最外层（`window`）一路向下寻找，直到找到你真正点击的那个元素。
2. **目标阶段（Target Phase）**：事件到达你点击的那个具体元素。
3. **冒泡阶段（Bubbling Phase）**：事件从点击的元素开始，**一路向上传递**回最外层（`window`）。**（我们平时的绝大多数事件处理，都是在冒泡阶段发生的）**。

---

### 三、 哪些事件“会冒泡”？哪些“不会冒泡”？（教你如何选择）

并不是所有的事件都会往上冒泡。作为开发者，你需要学会在不同的场景下**选择合适的事件**：

#### 1. 会冒泡的事件（绝大多数交互事件）

- **点击类**：`click`、`dblclick`、`mousedown`、`mouseup`
- **键盘类**：`keydown`、`keyup`、`keypress`
- **表单类**：`submit`、`change`、`input`
- **悬停类（会冒泡版）**：`mouseover`、`mouseout`（鼠标移入移出子元素也会触发父元素的冒泡）

#### 2. 不会冒泡的事件（特例）

有些事件比较“高冷”，它们只在目标元素上触发，绝对不往上递：

- **焦点类**：`focus`、`blur`（它们有对应的冒泡版本叫 `focusin` 和 `focusout`）
- **悬停类（不冒泡版）**：`mouseenter`、`mouseleave`（只在进入/离开绑定元素时触发，进入子元素不冒泡）
- **媒体与资源**：`scroll`（滚动）、`load`（加载）、`resize`（缩放）

---

### 四、 实战中如何“选择”和控制冒泡？（非常重要）

在实际写代码时，由于冒泡的存在，我们要做出以下三种重要的“选择”：

#### 选择 1：阻止冒泡（Stop Propagation）

**场景**：你写了一个“弹窗”，点击弹窗外黑色遮罩会关闭弹窗，但是点击弹窗内部的按钮时，不应该关闭弹窗。
**问题**：因为点击内部按钮时，`click` 事件会冒泡到外部的遮罩层，导致弹窗被意外关闭。
**解决**：使用 `event.stopPropagation()` 阻止事件继续往上冒泡。

```javascript
// 内部按钮的点击事件
button.addEventListener("click", (event) => {
  console.log("按钮被点击了");
  event.stopPropagation(); // 阻止气泡往上飘，遮罩层就收不到这个点击事件了
});
```

#### 选择 2：事件委托 / 事件代理（Event Delegation）

这是开发中最省内存、最优雅的选择，**完全依赖于冒泡机制**。
**场景**：你有一个列表 `<ul>`，里面有 1000 个 `<li>`。如果给每个 `<li>` 都绑定一个 `click` 监听器，页面会卡顿。
**解决**：由于冒泡，无论你点哪个 `<li>`，点击事件最终都会飘到父元素 `<ul>` 上。所以你**只需要在 `<ul>` 上绑定一个事件**即可：

```javascript
const ul = document.querySelector("ul");

ul.addEventListener("click", (event) => {
  // 通过 event.target 就能知道用户具体点的是哪个 li
  if (event.target.tagName === "LI") {
    console.log("你点击了列表项：", event.target.innerText);
  }
});
```

#### 选择 3：监听“捕获阶段”还是“冒泡阶段”？

日常写 `addEventListener` 时，我们默认都是在**冒泡阶段**触发事件。
如果你需要改变这个行为，可以通过第三个参数来选择：

```javascript
// 默认（第三个参数为 false 或不写）：在【冒泡阶段】触发
element.addEventListener("click", handler, false);

// 设置为 true：在【捕获阶段】触发（极少用，除非你想在事件到达子元素前强行拦截它）
element.addEventListener("click", handler, true);
```

### 总结

1. **冒泡**就是事件像气泡一样“从内向外”、“从子到父”传递的过程。
2. 像 `click`、`keydown` 默认都会冒泡，我们可以利用这一点做**事件委托**（把事件绑定在父级，省内存）。
3. 如果子元素的点击干扰了父元素，我们可以用 `event.stopPropagation()` **阻止冒泡**。
